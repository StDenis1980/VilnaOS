# Каталог програм для Gloxi

Маніфести програм із Flatpak, якими Gloxi може користуватися через Herkos ([ADR 0017](../../docs/adr/0017-third-party-mcp-servers.md), етап 2). Пакет `herkos-manifests` ставить їх у `/usr/share/herkos/manifests/` і для кожного робить юніт `vilna-mcp-ext-<назва>@.service` (`herkosd ext-unit`). Формат — [`../docs/protocol.md`](../docs/protocol.md), розд. 5. Кожна програма вимкнена, доки людина не ввімкне її на сторінці «Програми для Gloxi».

| Маніфест | Програма | Сервер MCP | Теки |
| --- | --- | --- | --- |
| `io.github.stdenis1980.tintatexto.toml` | Tinta Texto | `wordcraft-cli mcp` | `--automation-read-root`, `--automation-write-root` |
| `io.github.stdenis1980.tintacalculo.toml` | Tinta Calculo | `gridcraft-cli mcp` | те саме |
| `io.github.stdenis1980.tintapresenta.toml` | Tinta Presenta | `deckcraft-cli mcp` | те саме |
| `io.github.stdenis1980.tintapdf.toml` | Tinta PDF | `pdfcraft-cli mcp` | те саме |
| `io.github.stdenis1980.ibercorreo.toml` | Tinta Correo | `ibercorreo-cli mcp` | немає (поштова скринька) |

## Як задано рівні

- Документ, відкритий сервером, живе в його пам'яті, доки його не збережуть. Тому редагування — R1, а запис файлу — R2. Herkos не може зробити копію файлу перед записом, тож запис щоразу питає (R3, «її не можна скасувати»).
- Усе, що читає документ, пошту, події чи контакти, — зовнішній вміст: після нього сеанс забруднений (permissions.md, розд. 6).
- Загальні інструменти (`execute`, `batch`, `execute_command`, `run_command`) мають таблицю `[commands]`. Команда, якої в ній немає, — R4.
- Заборонено: друк, надсилання будь-чого з пристрою (пропозиції слів, звіти про помилки, «поділитися»), макроси й сценарії, посилання й медіа в інших програмах, шрифти програми.
- Не в каталозі (отже, заборонено): знімки екрана й кліки, рендер сторінок у картинки (модель Gloxi їх не бачить), підпис і сценарії в Tinta PDF, пакетна обробка тек, надсилання листів.
- Мережі немає в жодної програми. Друку теж (`--nosocket=cups`).

## Що ще не працює

- **Кілька дозволених тек.** Herkos передає прапорець тек для кожної дозволеної теки, а програми Tinta приймають кожен прапорець лише раз. Поки працює одна тека.
- **Відкрите вікно Correo.** Коли вікно Correo відкрите, сервер передає команди йому через локальний порт, але в пісочниці без мережі він до вікна не дістанеться (tintaoffice-web#27).
- **Вкладення.** У Correo ще немає інструмента, що зберігає вкладення в теку, тож «знайди рахунок у пошті й збережи PDF» поки неможливе.
- **Сталі id команд.** Таблиці `[commands]` звірено з кодом Tinta на 2026-11-05; тест-знімок id з боку Tinta — запит tintaoffice-web#33. Перейменована команда стане R4, а не небезпечнішою.
- Перевірка на образі Vilna зі справжніми Flatpak Tinta ще попереду (ноутбук).
