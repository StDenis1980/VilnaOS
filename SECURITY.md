# Безпека / Security

Про вразливості у Vilna OS, Gloxi чи Herkos повідомляйте **приватно**: [GitHub Security Advisories](https://github.com/StDenis1980/VilnaOS/security/advisories/new). Не відкривайте для цього публічний issue. Намагаємося відповісти протягом тижня; мови — українська, англійська, іспанська.

Please report vulnerabilities in Vilna OS, Gloxi or Herkos **privately** through [GitHub Security Advisories](https://github.com/StDenis1980/VilnaOS/security/advisories/new), not in a public issue. We try to reply within a week, in Ukrainian, English or Spanish.

Gloxi 0.1 is a preview: in a regular Linux session Herkos runs in the same sandbox as Gloxi and does not give the guarantees it will have in Vilna OS. Reports about that boundary are still welcome.
