# Vilna

[English](README.md) · **Українська** · [Español](README.es.md)

Vilna — вільна операційна система на базі Linux для всієї Європи, із вбудованим AI-асистентом **Gloxi** і шаром безпеки **Herkos**, через який проходить кожна дія асистента.

*Free as in freedom.*

> **Стан: ранній етап розробки.** Випусків ще немає. Перший випуск, **Gloxi 0.1 preview** для звичайного Linux з GNOME, заплановано на кінець січня 2027 року. Зібрати й запустити його з коду можна вже зараз: див. [Перший запуск](docs/getting-started.uk.md).

## Що таке Vilna

- **База:** спершу openSUSE Aeon (GNOME), пізніше Kalpa (KDE). Система незмінна, оновлення транзакційні, відкат через знімки btrfs. Запасний варіант — Fedora Atomic (bootc).
- **Gloxi** — асистент. Працює як системний сервіс, уміє працювати з файлами, програмами й налаштуваннями, веде календар і допомагає організувати час. Сам системи не торкається.
- **Herkos** — шар безпеки. Кожна дія, яку хоче виконати Gloxi, проходить через єдиний шлюз дозволів: він перевіряє рівень ризику, за потреби питає людину і веде журнал, який неможливо непомітно змінити. Також містить фільтр prompt injection (Keros) і скасування дій через журнал і знімки (Mitos). Специфікація: [`herkos/docs/permissions.md`](herkos/docs/permissions.md).
- **Шлюз приватності.** Перш ніж щось піде в хмарну модель, особисті дані (пошта, телефони, IBAN, номери документів, ключі й паролі) замінюються на пристрої на `[EMAIL_1]` тощо, а у відповідь повертаються справжні значення.
- **Інструменти** — MCP-сервери: файли, програми, налаштування, календар CalDAV, пошта IMAP.
- **Моделі.** Маршрутизатор відправляє приватні й прості запити до малої локальної моделі, а складні — у хмару, лише якщо людина ввімкнула хмару і дала свій ключ. Локальна модель за замовчуванням — Qwen3 4B ([ADR 0008](docs/adr/0008-default-local-model.md)); її можна замінити будь-яким OpenAI-сумісним сервером.
- **Мінімальне залізо:** Intel Core 8-го покоління або AMD Ryzen 2000, 8 ГБ RAM. Для зручної роботи з локальною моделлю радимо 16 ГБ.

## Спробувати Gloxi 0.1 preview

Поки що Gloxi запускається як збірка для розробки на Fedora, Ubuntu, openSUSE Aeon чи іншому Linux з Python 3.11 або новішим. Коротко:

```sh
llama-server -hf Qwen/Qwen3-4B-GGUF:Q4_K_M --port 8080 -c 4096 --jinja \
  --chat-template-kwargs '{"enable_thinking":false}'

git clone https://github.com/StDenis1980/VilnaOS.git
cd VilnaOS/gloxi
uv sync
uv run gloxi
```

Повна інструкція — як встановити llama.cpp і uv, вікно GTK, файли через Herkos, хмарна модель за бажанням і типові проблеми: [docs/getting-started.uk.md](docs/getting-started.uk.md).

## Структура репозиторію

Це монорепозиторій: кожен компонент живе у власній папці верхнього рівня з власним `README.md`.

| Папка | Що там |
| --- | --- |
| [`gloxi/`](gloxi/) | Асистент Gloxi: чат у терміналі, вікно GTK, маршрутизатор моделей, клієнт інструменту «файли» |
| [`herkos/`](herkos/) | Шар безпеки: шлюз дозволів, Keros, Mitos. Herkos-lite (Python) для Gloxi 0.1 |
| [`privacy-gateway/`](privacy-gateway/) | Бібліотека шлюзу приватності: оборотне маскування на пристрої (Apache-2.0) |
| [`mcp/`](mcp/) | MCP-сервери інструментів, першим — «файли» (Apache-2.0) |
| [`sdk/`](sdk/) | SDK для сторонніх розробників (Apache-2.0) |
| [`image/`](image/) | Образ системи Vilna на openSUSE Aeon / Kalpa |
| [`shell-extension/`](shell-extension/) | Розширення GNOME Shell: латинська розкладка в полях паролів, Gloxi поверх усіх вікон, смуга екрана під панель Gloxi |
| [`backup/`](backup/) | Зашифровані резервні копії даних Vilna (restic, ключі в Herkos) |
| [`obs/`](obs/) | Проєкт і RPM-пакети Vilna в Open Build Service |
| [`docs/`](docs/) | Дорожня карта, [архітектурні рішення](docs/adr/), [заміри](docs/benchmarks.md), [бриф дизайну](docs/design/brief.md) |

Більшість проєктних документів поки українською. Вхідні документи, цей README та інструкція першого запуску, є англійською, українською та іспанською.
