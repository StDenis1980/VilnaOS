# Значки картки годинника

`vilna-clock-world-symbolic.svg`, `vilna-clock-stopwatch-symbolic.svg` і `vilna-clock-timer-symbolic.svg` — меню картки годинника (`clockCard.js`): світовий час, секундомір, таймер. Тема Adwaita таких символьних значків не має.

Намальовано для Vilna з нуля (прості кола й лінії, 16×16), ліцензія GPL-3.0-or-later, як і розширення.
