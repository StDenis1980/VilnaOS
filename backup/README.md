# Vilna Backup

Зашифровані резервні копії даних Vilna: налаштування, дані Gloxi і Herkos, база KeePassXC, обрані папки. Усе шифрується на пристрої у форматі restic; ключі тримає Herkos.

Стан: лише специфікація. Рішення — [ADR 0007](../docs/adr/0007-encrypted-backup.md), деталі — [`docs/design.md`](docs/design.md).
