# MCP-сервери інструментів

Інструменти, через які Herkos виконує дії Gloxi: кожен — окремий MCP-сервер у власній підпапці (наприклад, `mcp/files/`).

| Сервер | Що робить |
| --- | --- |
| [`apps/`](apps/) | Програми: пошук на Flathub і у сховищі Vilna («Рекомендовано Vilna» спершу), опис, встановлення, оновлення і видалення Flatpak (R0, R3), відкрити встановлену програму (R1); ADR 0012 |
| [`backup/`](backup/) | Зашифровані копії: стан, список, розміри, що і як часто зберігати, копія зараз, відновлення в нову папку (R0–R2; прототип) |
| [`installer/`](installer/) | Установник: читає залізо, диски, мережі; змінює лише план встановлення; формат плану і його валідатор (альфа) |
| [`mail/`](mail/) | Пошта з облікових записів GNOME Online Accounts: читання (IMAP, R1), чернетки (R2), надсилання (SMTP) лише після «так» людини щоразу (R4); ADR 0030 |
| [`desktop/`](desktop/) | Стільниця GNOME через D-Bus (батарея, сповіщення, програвачі, блокування екрана), дозволи порталів Flatpak (камера, мікрофон, місцезнаходження…), вікна інших програм через AT-SPI без захищених програм; кожен сервер — за фільтром D-Bus зі свого маніфесту; ADR 0031 |
| [`files/`](files/) | Файли в дозволених папках: список, пошук, читання, створення, зміна, видалення, скасування змін (Gloxi 0.1) |
