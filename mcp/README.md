# MCP-сервери інструментів

Інструменти, через які Herkos виконує дії Gloxi: кожен — окремий MCP-сервер у власній підпапці (наприклад, `mcp/files/`).

| Сервер | Що робить |
| --- | --- |
| [`files/`](files/) | Файли в дозволених папках: список, пошук, читання, створення, зміна, видалення, скасування змін (Gloxi 0.1) |
