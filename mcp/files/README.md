# vilna-mcp-files

MCP-сервер «файли» для Gloxi: список, пошук, читання, створення, зміна й видалення текстових файлів у дозволених папках. Перед кожною зміною зберігає резервну копію, тож зміну можна скасувати (`restore`). Резервні копії зберігаються **30 днів**, як історія версій і кошик в OneDrive, потім видаляються автоматично (`--keep-days`).

Операція `restore_snapshot` повертає файли зі знімка Mitos домашньої теки (`~/.snapshots/<N>/snapshot`, [ADR 0026](../../docs/adr/0026-mitos-btrfs-snapshots.md)): змінені й видалені — з того знімка, створені — видаляє, а файл, який людина змінила вже після дії (не збігається зі знімком `post`), не чіпає і повертає в `skipped`. Власної копії вона не робить: перед нею системний Herkos сам бере знімок. Теки `.snapshots` для інших операцій заборонені.

У Vilna сервер запускає лише Herkos, а не Gloxi: Herkos вирішує, чи можна виконати дію (маніфест `herkos/src/herkos/manifests/org.vilna.mcp.files.toml`), а сервер ще раз перевіряє, що шлях усередині дозволених папок.

```sh
uv run vilna-mcp-files --root ~/Documents --backup-dir ~/.local/state/herkos/backups/files
```

Транспорт — MCP через stdio (JSON-RPC 2.0, одне повідомлення на рядок). Ліцензія Apache-2.0 (див. [`../LICENSE`](../LICENSE)).
