# vilna-mcp-mail

MCP-сервер «пошта» для Gloxi ([ADR 0030](../../docs/adr/0030-gloxi-mail.md)): читати пошту, зберегти чернетку, надіслати лист. Облікові записи — з GNOME Online Accounts (Налаштування → Облікові записи в мережі): IMAP і SMTP, Google, Microsoft 365. Пароль чи ключ входу GOA дає щоразу, коли сервер підключається; сервер ніде його не зберігає й не пише в журнал.

| Операція | Що робить | Рівень у Herkos |
| --- | --- | --- |
| `list_accounts` | Поштові облікові записи | R0 |
| `list_folders` | Теки, скільки непрочитаних | R0 |
| `list_messages` | Найновіші листи теки | R1, чужий текст |
| `search_messages` | Пошук за словами, відправником, датами | R1, чужий текст |
| `read_message` | Текст листа, від кого й кому, назви вкладень | R1, чужий текст |
| `save_draft` | Зберегти лист у «Чернетки», не надсилаючи | R2, скасовується |
| `send` | Надіслати лист | **R4: щоразу, з показом усього листа** |
| `restore` | Прибрати чернетку, яку записав `save_draft` (скасування) | R2 |

- **Читання нічого не змінює**: теки відкриваються лише для читання (EXAMINE), листи — через `BODY.PEEK`, тож лишаються непрочитаними.
- **Що показано, те й надіслано.** `send` складає лист лише зі своїх аргументів: від кого (`account`), кому (`to`, `cc`, `bcc`), тема, текст, на який лист відповідь. Саме ці аргументи вікно Herkos показує для R4. Додаються лише технічні заголовки (дата, Message-ID, In-Reply-To). Вкладень поки немає. Копія листа йде в «Надіслані», якщо провайдер не робить цього сам (Gmail, Microsoft).
- **Лише шифровані з'єднання** (TLS або STARTTLS) з перевіркою сертифіката. Без шифрування або з «прийняти помилки сертифіката» — лише до самого комп'ютера (127.0.0.1, ::1, localhost), де працюють мости на кшталт Proton Mail Bridge.
- Межі: до 50 листів у списку, текст листа до 20 000 символів (довший обрізається, `text_truncated`), до 4 МіБ з сервера на лист; написати можна до 50 отримувачів і 50 000 символів.

```sh
uv run vilna-mcp-mail          # облікові записи GOA (потрібні PyGObject і typelib Goa 1.0)
uv run vilna-mcp-mail --demo   # вигадана скринька, нічого не надсилає; для тестів і показу
```

Транспорт — MCP через stdio (JSON-RPC 2.0, одне повідомлення на рядок). Запускає лише системний Herkos (`vilna-mcp-mail@.service`), не Herkos-lite. Ліцензія Apache-2.0 (див. [`../LICENSE`](../LICENSE)).
