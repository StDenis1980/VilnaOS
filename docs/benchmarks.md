# Заміри локальної моделі

Мета (дорожня карта, крок 16–29 листопада; [ADR 0004](adr/0004-local-model-engine.md)): з'ясувати, що реально тягне мала модель на 8 і 16 ГБ RAM, і обрати модель за замовчуванням для Gloxi 0.1 та образу Vilna.

## Набір команд

30 команд у [`gloxi/src/gloxi/bench/tasks.toml`](../gloxi/src/gloxi/bench/tasks.toml), у сім груп:

| Група | Скільки | Що перевіряє |
| --- | --- | --- |
| розмова | 6 | Короткі відповіді українською й англійською, проста арифметика, чесне «не знаю» |
| довідка | 4 | Пояснити щось про комп'ютер простими словами |
| текст | 5 | Переписати, стиснути, перекласти, скласти короткий лист |
| структура | 5 | Перетворити прохання на JSON-команду (`files.search`, `files.read`) або витягти дані: це знадобиться для інструментів через Herkos |
| маршрут | 3 | Чи може мала модель сама відрізнити просте прохання від складного |
| встановлення | 4 | Діалог встановлення ОС ([ADR 0006](adr/0006-conversational-installer.md)): одне питання за раз, попередження перед стиранням диска |
| безпека | 3 | Ін'єкція в тексті, який треба стиснути; небезпечна команда; пароль у чаті |

Перевірки автоматичні й грубі: мова відповіді, ключові слова, JSON, довжина. Вони відрізняють придатну відповідь від зламаної, але не хорошу від чудової, тому відповіді варто переглянути й очима (вони є у звіті). Усі імена, адреси й номери в завданнях вигадані.

## Як запустити

1. Запустіть модель у llama-server так, як її запускатиме Gloxi, наприклад:

   ```sh
   llama-server -m model.gguf --port 8080 -c 4096
   ```

2. Запустіть заміри (з папки `gloxi/`):

   ```sh
   uv run gloxi-bench --model назва-моделі-q4 --server-pid $(pgrep -f llama-server)
   ```

   `--server-pid` додає до звіту пікову пам'ять сервера моделі (`VmHWM`). `--only структура` запускає лише одну групу. Перший запит не рахується: він ще й завантажує модель.

3. Звіт з'явиться в `bench-results/` (Markdown і JSON): машина, пам'ять, скільки пройдено по групах, час до першого токена, увесь час, символи на секунду і кожна відповідь.

Під час замірів закрийте важкі програми, а ноутбук підключіть до мережі живлення.

## Машини

- **8 ГБ RAM**, без дискретної відеокарти: мінімальне залізо Vilna (Intel Core 8-го покоління / Ryzen 2000).
- **16 ГБ RAM**: рекомендоване залізо.

Обидві машини запускаємо з тими самими моделями й тим самим квантуванням (спершу Q4_K_M).

## Кандидати

Обов'язкова умова для моделі за замовчуванням — вільна ліцензія ваг, що дозволяє розповсюдження в складі ОС, зокрема комерційне, без обмежень для ЄС ([ADR 0004](adr/0004-local-model-engine.md), [`image/docs/composition.md`](../image/docs/composition.md)). Ліцензію кожного кандидата перевіряємо в картці конкретної моделі перед вибором: в одній родині вона може відрізнятися за розміром.

| Модель | Розмір | Ліцензія (за карткою моделі, перевірити) |
| --- | --- | --- |
| Qwen3 | 1.7B, 4B | Apache-2.0 |
| Qwen2.5 Instruct | 1.5B | Apache-2.0 (3B має іншу, невільну ліцензію) |
| SmolLM3 | 3B | Apache-2.0 |
| IBM Granite Instruct | 2B | Apache-2.0 |
| Phi-4-mini Instruct | 3.8B | MIT |

Llama 3.2 і Gemma для моделі за замовчуванням не підходять через власні ліцензії, але їх можна заміряти для порівняння.

## Як обираємо

1. На 8 ГБ модель разом із системою і Gloxi вміщається в пам'ять без постійного свопу; час до першого токена на простій команді — кілька секунд, а не десятки.
2. Українською відповідає без переходу на іншу мову (група «розмова» і «довідка»).
3. Тримає формат JSON (група «структура»): без цього інструменти через Herkos не працюватимуть локально.
4. Не виконує інструкції з чужого тексту і попереджає перед руйнівними діями (група «безпека» і «встановлення»).

Результати кожного запуску додаємо в таблицю нижче, а рішення записуємо в ADR.
