# Установник і Herkos з Orca: перевірка наживо

Статус: чернетка, 2026-11-23. Пункт 34 плану альфи Vilna Blavet.

Автоматичні тести (`installer/tests/test_a11y_live.py`, `herkos/tests/test_a11y_live.py`) читають дерево AT-SPI так, як його читає Orca, але не чують самої Orca і не бачать GNOME на Wayland. Цей сценарій — для живої перевірки у VM: лише клавіатура, монітор можна вимкнути або не дивитися на нього.

## Підготовка

- Живий образ Vilna-Live (остання збірка OBS) у VM з 4 vCPU і 6 ГБ RAM, звук увімкнено (Orca говорить через speech-dispatcher).
- Миша не потрібна. Якщо VM перехоплює її — не торкатися.
- Записувати: що Orca сказала (дослівно, коли це важливо), що мала сказати, і на якому кроці.

## 1. Перший екран

| Дія | Що має сказати Orca |
|---|---|
| Super+Alt+S (або кнопка «Читач екрана») | Orca вмикається |
| Tab до кнопки читача екрана | «Читач екрана, перемикач, натиснуто» (раніше: лише «перемикач») |
| Tab по мовах | назву кожної мови її мовою, «перемикач» |
| Tab до «Далі з Gloxi», Enter | відкривається розмова |

## 2. Розмова з Gloxi

| Дія | Що має сказати Orca |
|---|---|
| вікно відкрилося | фокус у полі «Повідомлення для Gloxi»; Orca читає першу репліку Gloxi сама (оголошення) |
| написати відповідь, Enter | «Gloxi думає…», потім текст відповіді Gloxi без руху фокуса |
| з'являється поле пароля | фокус у полі, Orca читає його назву (пароль Wi-Fi чи облікового запису) |
| ввести короткий пароль, «Зберегти» | Orca каже, що не так («Щонайменше 8 символів.») |
| Shift+Tab з поля повідомлення | «Розмова з Gloxi, панель»; далі «План, панель» і «Змінити: …» |

## 3. Класичний майстер («Без асистента»)

| Крок | Дія | Що має сказати Orca |
|---|---|---|
| будь-який | «Далі» | «Крок N з 9: …», фокус на першому елементі кроку |
| Мови | Tab по мовах | одна зупинка на мову: «Українська, прапорець, позначено» |
| Мережа | фокус на «Без мережі», Tab | «Шукати мережі ще раз», далі мережі Wi-Fi: «DemoHome, перемикач, не вибрано, 82 %, захищена паролем» |
| Мережа | стрілки вниз/вгору по мережах, пробіл | перехід між мережами; пробіл обирає; для захищеної — фокус у полі пароля |
| Диск | Tab, стрілки | «Стерти весь диск і встановити Vilna, перемикач… Усе на цьому диску буде стерто: Windows» |
| Шифрування | фокус на вибраному способі, Tab ×3; потім Shift+Tab назад і стрілка вниз ×3 | обидва рази всі чотири способи досяжні (Build12.19: стрілка вниз і Tab ішли з вибраного на «Назад») |
| Обліковий запис | Tab | «Пароль» (раніше — обрізане «Пароль для») |
| Приватність, VPN | стрілки | кожен варіант разом із поясненням під ним |
| Ручна розмітка | «Відкрити редактор розділів», «Додати розділ» | «Новий розділ 1: Призначення», «Новий розділ 1: Розмір, GiB, 0,5», «Прибрати: Новий розділ 1» |
| Підсумок | Tab по рядках | назва рядка і значення («Диск, Стерти весь диск · …») |

## 4. Екран Herkos в установнику

| Дія | Що має сказати Orca |
|---|---|
| екран відкрився | діалог: Orca читає заголовок, пояснення і що станеться з дисками, потім поле «Остання група ключа відновлення» |
| «Прочитати ключ уголос» | ключ голосом (speech-dispatcher), не через Orca |
| ввести неправильну групу | «Це не остання група…» без руху фокуса |
| ввести правильну | «Так. Ключ збережено.» |
| позначити «Я розумію…», Tab до «Стерти й встановити», через 3 с Enter | встановлення починається; Orca називає кожен етап («Запис Vilna на диск» тощо) |

## 5. Вікна Herkos у системі

| Дія | Що має сказати Orca |
|---|---|
| Gloxi просить дозволу (напр. стерти файл, R4) | діалог: Orca читає прохання, рівень ризику словами, причину й що саме буде зроблено; фокус на «Відхилити» |
| «Дозволити» без позначки «Я прочитав…» | кнопка недоступна |
| «Дозволи» → «Журнал» | «Скасувати: Gloxi змінив файл: …» (раніше в кожному рядку однакове «Скасувати») |
| «Дозволи» → «Дозволи» | «Змінити файл, Завжди · у Documents», «Рівень ризику R2», «Відкликати: Змінити файл» |

## 6. Бічна панель Gloxi

Увімкнути: `gsettings set org.gnome.shell.extensions.vilna gloxi-dock true`, потім Super+G.

| Дія | Що має сказати Orca |
|---|---|
| Super+G | фокус у полі «Напишіть Gloxi»; Orca читає назву поля |
| написати питання, Enter | коли відповідь готова, Orca читає її цілою: «Gloxi: …», а для дії ще й картку («Settings: dark theme · Готово») |
| Tab з панелі в інше вікно, поки Gloxi відповідає | відповідь однаково звучить (питали з панелі) |
| питання з вікна Gloxi, панель відкрита, фокус у вікні | відповідь читає вікно, а панель мовчить: не двічі |
| сповіщення Gloxi (нагадування), поки панель відкрита | Orca читає «Нагадування: …» один раз, банера немає |
| Escape | панель закривається, фокус у попереднє вікно |

## Що відомо заздалегідь

- Перевірено лише в контейнері: GTK 4.14, libadwaita 1.5, Xvfb, без Orca. У Vilna новіші GTK і libadwaita; виправлення не залежать від версії, але голос Orca і Wayland — лише у VM.
- Оголошення (`announce`) потребують GTK 4.14+ і Orca 46+.
- Ключ відновлення Orca не читає навмисно (ADR 0029): лише кнопка «Прочитати ключ уголос».
- Рядки журналу Herkos (розгортальні) читають лише назву, без часу й результату: підзаголовок `Adw.ExpanderRow` не дістати.
