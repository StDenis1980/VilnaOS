# 0021. Vilna Skia: шлюз приватності як окремий продукт для Windows, macOS і Linux

- Стан: Запропоновано; назву погоджено (Denys, 2026-11-06), решта чекає рішення
- Дата: 2026-11-06
- Пов'язано: [`privacy-gateway/`](../../privacy-gateway/README.md), [ADR 0001](0001-licensing.md), [ADR 0003](0003-implementation-language.md), [ADR 0009](0009-languages.md), [ADR 0013](0013-herkos-rust.md), [ADR 0016](0016-gloxi-for-code-editors.md)

## Контекст

Шлюз приватності вже працює в Gloxi: перед запитом у хмару він на пристрої замінює чутливі дані нумерованими замінниками (`[EMAIL_1]`), а потім повертає справжні значення у відповідь. Він знає ключі й паролі, пошту, телефони, IBAN, картки, РНОКПП, паспорти, IP і посилання на профілі, а також відновлює замінники, які модель трохи змінила. Код — бібліотека Python під Apache-2.0, без залежностей від Gloxi.

Тією самою проблемою переймаються люди, які не ставитимуть Vilna: юристи, лікарі, бухгалтери, журналісти, розробники на Windows і macOS вставляють дані клієнтів у ChatGPT, Claude, Gemini чи Le Chat. Denys запропонував випустити шлюз окремим продуктом для будь-кого: для будь-якого ШІ або для переліку дозволених.

Схожі продукти вже є (розширення браузера, хмарні та локальні проксі, корпоративні DLP), але серед переглянутих жоден не поєднує всього разом: розпізнавання лише на пристрої, повернення значень у відповідь, мови й формати документів України та ЄС і відкритий код.

Обмеження: працює одна людина, Gloxi 0.1 виходить у січні 2027, Gloxi 0.2 у лютому — березні, образ ОС у квітні — вересні 2027. Розширення браузера не може виконувати Python.

## Рішення (пропозиція)

1. **Назва.** Поки продукт — частина сімейства Vilna: **Vilna Skia** (грецьке σκιά, «тінь»). Згодом — окремий бренд **SkiaGuard** (домен і назва пакета `skiaguard`). Перед виділенням бренду перевірити торговельні марки в EUIPO: Skia — також назва графічної бібліотеки Google.
2. **Одне ядро, кілька форм.**
   - Бібліотека (PyPI, згодом crates.io і npm).
   - Локальний проксі на `127.0.0.1`, сумісний з OpenAI і Anthropic, для будь-якої програми з полем `base_url`. Це той самий проксі, що й «Gloxi для інших програм» з [ADR 0016](0016-gloxi-for-code-editors.md): одна реалізація для обох.
   - MCP-сервер з інструментами `mask`, `unmask`, `scan`.
   - Розширення браузера (Chrome, Edge, Firefox; Safari пізніше) для chatgpt.com, claude.ai, gemini.google.com, chat.mistral.ai.
   - Застосунок у треї для Windows, macOS і Linux: тримає проксі, словник і модель імен, маскує буфер обміну за гарячою клавішею.
   - Мобільні — не раніше 2028 і лише як «Поділитися → замаскувати й скопіювати»: чужі застосунки на телефоні перехопити не можна.
3. **Перелік ШІ** — одна політика: список сервісів і для кожного режим «маскувати», «лише попереджати» або «заборонити». Для людини за замовчуванням — «маскувати всюди»; для організації адміністратор задає дозволені сервіси.
4. **Ядро на Rust** (`privacy-gateway/core`): детектори, замінники, відновлення, потік. Збирається в WASM для розширення, у модуль Python (PyO3) для Gloxi без зміни API і в нативну бібліотеку для проксі, застосунку й системного Herkos ([ADR 0013](0013-herkos-rust.md)). Поточні тести стають спільним набором JSON-прикладів, який мають проходити обидві реалізації, доки жива версія на Python.
5. **Чого не робимо:** системний HTTPS-проксі з власним кореневим сертифікатом, як у корпоративних DLP. Він послаблює захист усього комп'ютера і суперечить ідеї Herkos.
6. **Незмінні принципи.**
   - Розпізнавання лише на пристрої; текст не йде на сервери Vilna ніколи, навіть для перевірки підписки.
   - Без телеметрії за замовчуванням.
   - Справжні значення — лише в пам'яті або зашифровано в сховищі ключів ОС (Keychain, Credential Manager, Secret Service).
   - Чесно: це мінімізація даних, а не гарантована анонімізація. Перед надсиланням людина бачить, що сховано. Якщо адаптер сайту зламався, розширення блокує надсилання й попереджає, а не пропускає текст мовчки.
   - Тестові дані — лише вигадані.
7. **Ліцензія.** Ядро, бібліотека, проксі й MCP лишаються Apache-2.0 ([ADR 0001](0001-licensing.md)). Ліцензію розширення й застосунку (Apache-2.0 чи GPL-3.0-or-later) вирішити до їхнього випуску.
8. **Код** лишається в монорепо, у `privacy-gateway/` (`core`, `python`, `proxy`, `mcp`, `extension`, `desktop`), з власними тегами випусків `skia-v<версія>`. Окреме репо — лише якщо з'являться сторонні учасники.

## Етапи

| Коли | Що | Умова переходу |
| --- | --- | --- |
| Листопад — грудень 2026 | Лише робота, потрібна й Gloxi: формати документів ЄС (DNI/NIE, PESEL, Steuer-ID, NIR, codice fiscale, CNP, rodné číslo, asmens kodas), замір стійкого формату замінників на кількох постачальниках, замір малої моделі імен на 10 мовах ([ADR 0009](0009-languages.md)) | Gloxi 0.1 вийшов |
| Лютий — березень 2027 | Бібліотека на PyPI, локальний проксі, MCP-сервер (разом із проксі ADR 0016) | — |
| Квітень — червень 2027 | Ядро на Rust + WASM, розширення для чотирьох сайтів | ≥ 1 000 активних користувачів розширення |
| Липень — грудень 2027 | Застосунок у треї, модель імен у вільному тексті, політики для організацій, розгортання через MDM | — |
| 2028 | Android, потім iOS | — |

Якщо часу забракне, застосунок і політики для організацій переходять на 2028, а розширення лишається.

## Наслідки

- Шлюз стає першим продуктом Vilna для людей на Windows і macOS, ще до образу ОС.
- Кожен крок до Gloxi 0.1 одночасно покращує Gloxi, тож графік 0.1 не зсувається.
- З'являється ще одна підтримувана поверхня: адаптери сайтів ШІ ламаються, коли сайти змінюють розмітку. Потрібна щоденна автоматична перевірка (Playwright) на вигаданих даних.
- Потрібні підписування застосунків для macOS і Windows і облікові записи в магазинах розширень.
- Гроші й тарифи — окреме рішення поза цим ADR.

## Розглянуті варіанти

- **Лише бібліотека й проксі.** Найменше роботи, але більшість людей користується ШІ через сайти, куди проксі не дістається.
- **Окрема реалізація правил на TypeScript для розширення.** Швидше на старті, але два набори правил неминуче розійдуться.
- **Хмарне розпізнавання, як у частини конкурентів.** Точніше на старті, але суперечить головній обіцянці: дані не залишають пристрій.
