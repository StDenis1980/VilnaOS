# 0019. Месенджери: що радить Vilna і як Gloxi з ними працює

- Стан: Прийнято (Denys, 2026-11-05)
- Дата: 2026-11-05
- Пов'язано: [ADR 0012](0012-recommended-apps-and-install-via-gloxi.md), [ADR 0014](0014-remote-wipe.md), [ADR 0015](0015-gloxi-voice.md), [ADR 0017](0017-third-party-mcp-servers.md), [`permissions.md`](../../herkos/docs/permissions.md) розд. 4, 6, 8, 9.5, [`picks.toml`](../../obs/packages/vilna-software-picks/picks.toml)

## Контекст

Месенджер — друга після пошти програма, де людина листується з іншими людьми. Пошту у Vilna замінює Tinta Correo ([ADR 0011](0011-default-office-suite.md)), а для месенджерів рішення ще не було. Треба вирішити дві речі: що Vilna радить у добірці «Рекомендовано Vilna» ([ADR 0012](0012-recommended-apps-and-install-via-gloxi.md)) і чи може Gloxi читати та надсилати повідомлення.

Ми порівняли Matrix (Fractal, Element), Delta Chat, Signal, SimpleX, Session, Threema, Wire, XMPP (Dino), Briar, Telegram і WhatsApp за шифруванням, ліцензією, юрисдикцією і наявністю Flatpak (стан на листопад 2026):

| Месенджер | Чому так |
| --- | --- |
| Matrix (Fractal) | Вільний федеративний стандарт, свій сервер можна мати в ЄС, наскрізне шифрування типово в приватних чатах. Fractal уже в добірці |
| Delta Chat | Вільний, працює поверх пошти, без телефону; команда в ЄС; офіційний Flatpak і офіційний JSON-RPC сервер |
| SimpleX Chat | Вільний, без ідентифікатора користувача, найкраща анонімність |
| Signal | Найсильніше шифрування і найбільше людей серед безпечних месенджерів; але США, завжди потрібен телефон, Flatpak на Flathub збирає спільнота, офіційно — лише `.deb` |
| Session | Без прямої секретності до протоколу V2 (оголошено в грудні 2025), мережа прив'язана до токена — чекаємо V2 і аудиту |
| Threema, Wire | Європейські й надійні; Threema має закритий сервер і новий клієнт для Linux лише в беті, Wire зосереджений на бізнесі |
| Telegram | Звичайні чати й групи без наскрізного шифрування, сервер закритий |
| WhatsApp | Закритий, програми для Linux немає |

## Рішення

1. **Добірка.** У `picks.toml` з'являється розділ «Спілкування» (`communication`): Fractal (переходить із «Роботи»), Delta Chat, SimpleX Chat і Signal. Жоден не ставиться за замовчуванням. Telegram, WhatsApp, Threema і Session у добірку не входять; людина ставить їх сама, а якщо просить Gloxi, Gloxi ставить (R3, ADR 0012) і одним реченням каже про обмеження (наприклад, що звичайні чати Telegram не шифруються наскрізно).
2. **Виняток для Signal у критеріях ADR 0012.** Критерій «програма підтверджена на Flathub (verified)» доповнюємо: програму, яку зібрала спільнота Flathub (`source = "flathub-community"`), можна взяти в добірку лише окремим рішенням ADR, якщо офіційного Flatpak немає, а програма важлива для безпеки людини. Опис `why` прямо каже, що збірка неофіційна, а діалог Herkos показує, що розробник не підтверджений. Зараз так позначено лише Signal. Щоб лишитися в межах 30–60 програм, з добірки прибрано три вузькі програми: Solanum, Kooha (запис екрана вже є в GNOME Shell) і Wike.
3. **Gloxi працює з месенджерами лише через MCP-сервери під Herkos** за [ADR 0017](0017-third-party-mcp-servers.md): сервер запускає `herkosd` у власній пісочниці, у нього є маніфест у `herkos-manifests` і зафіксовані описи інструментів. Порядок: Matrix (на `matrix-rust-sdk`), потім Delta Chat (`deltachat-rpc-server`), потім Signal (лише після оцінки неофіційного `signal-cli`). Telegram (TDLib) — не пріоритет. WhatsApp — не робимо: дозволеного способу для особистих облікових записів немає.
4. **Окремий пристрій для Gloxi.** MCP-сервер входить у месенджер як новий пристрій «Gloxi», який людина підтверджує в своїй програмі. Його можна відкликати з телефона, співрозмовники бачать його як новий пристрій, ключі зберігає Herkos, а віддалене стирання ([ADR 0014](0014-remote-wipe.md)) стирає і їх.
5. **Рівні ризику в маніфесті** (`permissions.md` розд. 4):

   | Операція | Рівень |
   | --- | --- |
   | Список чатів, кількість непрочитаних | R1 |
   | Прочитати чат, підсумок (лише чати, які людина дозволила; дозвіл на кожен чат) | R1 |
   | Чернетка відповіді в полі введення месенджера (надсилає людина) | R2 |
   | Надіслати повідомлення, файл, переслати, написати новій людині | R4, щоразу, з точним текстом і адресатом |
   | Видалити повідомлення, вийти з групи, заблокувати | R4 (відкату немає) |
   | Автовідповіді, зміна налаштувань безпеки, експорт ключів, підтвердження нових пристроїв | Заборонено: таких інструментів у маніфесті немає |

6. **Вхідні повідомлення — зовнішній вміст.** Сервер позначає кожне повідомлення автором і часом, Herkos ставить на сесію `tainted`, Keros перевіряє текст до того, як його побачить модель (розд. 6). Будь-яка дія назовні після прочитаного чату підвищується на рівень, а діалог Herkos каже, з чийого повідомлення прийшла вказівка. Посилання і вкладення з чатів Gloxi сам не відкриває.
7. **Чужі повідомлення не йдуть у хмару без явної згоди.** У них персональні дані інших людей, тому типово працює лише локальна модель. Хмару людина може дозволити для окремого чату, і тоді все йде через шлюз приватності (розд. 8). Наскрізно зашифрований чат не повинен тихо втрачати захист через помічника.

## Наслідки

- Добірка: 60 програм, 8 розділів; `build_picks.py` знає джерело `flathub-community`.
- Delta Chat (delta.chat) і SimpleX Chat (simplex.chat) підтверджені на Flathub (verified), перевірив Denys 2026-11-05 на сторінках програм.
- Що Gloxi дасть людині: ранковий підсумок непрочитаного, чернетки відповідей, домовленості з чату в календар Tinta Correo (R2 з підтвердженням), голосові в текст на пристрої ([ADR 0015](0015-gloxi-voice.md)), попередження про шахрайські повідомлення.
- Коли: не раніше альфи (жовтень 2027 — березень 2028), після етапу 2 ADR 0017 (програми Tinta). У 0.2 — лише добірка.
- Далі: маніфест `vilna-mcp-matrix`, тест «повідомлення з prompt injection не може викликати надсилання без R4», перевірка на ноутбуці, що сервер Matrix працює в пісочниці `herkosd`.
- Власний месенджер Vilna не будуємо (як і VPN). Пізніше можливий власний сервер Matrix і chatmail під брендом Vilna в ЄС як платна послуга — окреме рішення.

## Розглянуті варіанти

- **Signal як головна рекомендація.** Найсильніше шифрування, але юрисдикція США, обов'язковий телефон і неофіційний Flatpak. Лишаємо в добірці, але не першим.
- **Не брати Signal зовсім, бо не verified.** Тоді людина однаково поставить ту саму збірку, лише без чесного попередження від Vilna.
- **Gloxi читає вікно месенджера через AT-SPI.** Ненадійно, ламається з оновленнями і не дає Herkos знати, що саме надсилається. Ні.
- **Підняти межу добірки до 65 програм.** Відкинуто: ADR 0012 тримає список коротким, тож прибрали три вузькі програми.
