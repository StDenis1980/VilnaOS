## Шаблон

```markdown
# NNNN. Назва

- Стан: Запропоновано | Прийнято | Замінено (NNNN)
- Дата: РРРР-ММ-ДД
- Пов'язано: посилання на roadmap, специфікації, інші ADR

## Контекст
Чому взагалі треба вирішувати і які є обмеження.

## Рішення
Що вирішили, коротко й однозначно.

## Наслідки
Що це дає, чим платимо, що треба зробити далі.

## Розглянуті варіанти
Що ще було на столі і чому ні.
```
