# 0009. Основні мови Vilna

- Стан: Прийнято (Denys, 2026-11-02)
- Дата: 2026-11-02
- Пов'язано: [roadmap](../roadmap.md) розд. 3 і 5, [ADR 0006](0006-conversational-installer.md), [ADR 0008](0008-default-local-model.md), [заміри](../benchmarks.md)

## Контекст

Gloxi говорить з людиною, а діалог встановлення ([ADR 0006](0006-conversational-installer.md)) взагалі не має іншого інтерфейсу, тож мова для Vilna важить більше, ніж для звичайної ОС. Перекласти всі мови однаково добре одна людина не зможе. Треба вибрати невеликий набір мов, за якість яких ми відповідаємо самі, а решту віддати спільноті.

## Рішення

Основні мови, які мають бути в гарному стані у власних частинах Vilna (Gloxi, Herkos, діалоги підтвердження, встановлювач і перший запуск, документація для людей):

| Мова | Код |
| --- | --- |
| українська | `uk` |
| англійська | `en` |
| іспанська | `es` |
| польська | `pl` |
| німецька | `de` |
| французька | `fr` |
| італійська | `it` |
| румунська | `ro` |
| чеська | `cs` |

«У гарному стані» означає: переклад повний (без англійських рядків на місці перекладу), його перечитала людина, яка добре знає мову, а Gloxi в цій мові проходить заміри (розмова, довідка, встановлення, безпека).

Решта мов, зокрема литовська та інші офіційні мови ЄС, перекладаються через спільноту (Weblate) і виходять, коли переклад готовий.

## Наслідки

- **Gloxi 0.1 (січень 2027).** Рядки інтерфейсу одразу йдуть через gettext, а каталоги заводимо для всіх дев'яти мов. Повністю перекладені й перечитані в 0.1 — українська й англійська, як у дорожній карті. Інші сім мов додаємо в міру перевірки, найпізніше до альфи.
- **Альфа і далі.** Кожен випуск має всі дев'ять мов повними. Рядок без перекладу в основній мові вважається помилкою, яку перевіряє CI.
- **Заміри моделі.** Набір тестових команд розширюємо до всіх дев'яти мов (щонайменше розмова, довідка, встановлення й безпека). Модель за замовчуванням має працювати в кожній із них; якщо ні, рішення [ADR 0008](0008-default-local-model.md) переглядаємо.
- **Шлюз приватності.** Підписані поля («Ім'я:», «Адреса:» тощо) і формати номерів документів, телефонів та адрес додаємо для країн цих мов.
- **Встановлювач.** Перше питання діалогу — вибір мови з цих дев'яти; інші мови доступні, якщо їхній переклад готовий.
- **Литовська** більше не входить до основних мов (у попередній версії дорожньої карти вона була). Її можна повернути окремим рішенням.

## Розглянуті варіанти

- **Лише українська й англійська.** Простіше, але Vilna розрахована на користувачів у всьому ЄС.
- **Усі офіційні мови ЄС одразу.** Понад двадцять мов: якість перевіряти нікому, а неякісний переклад у діалогах Herkos небезпечний, бо людина погоджується на дію, якої не зрозуміла.
