# Значки програм Vilna

Значки власних програм Vilna у стилі GNOME: прості об'ємні форми, світло згори, темніша «губа» знизу. Кольори з палітри логотипа (нічний синій `#1F345C`, синій `#2D6BFF`, золотий `#F5C24A`, помаранчевий `#F0963A`).

| Файл | Програма | Що на значку |
|---|---|---|
| `io.github.stdenis1980.Gloxi.svg` | Gloxi | Сова Gloxi (варіант A) |
| `vilna-backup.svg` | Копії | Три шари-копії і стрілка відновлення |
| `vilna-installer.svg` | Встановлення | Ноутбук, стрілка вниз і смуга поступу |
| `vilna-permissions.svg` | Дозволи (Herkos) | Щит, огорожа і галочка |

Кожен значок має пару `-symbolic.svg` 16×16 одним кольором: GNOME сам перефарбовує її під тему. Повний значок має розмір 128×128 і ставиться в `hicolor/scalable/apps`, а symbolic — у `hicolor/symbolic/apps`.

Gloxi уже бере свої значки з `gloxi/data/icons/`, Копії — у пакеті `vilna-backup` (вікно `vilna-backup-gui`). Значки Встановлення і Дозволів підуть у пакети цих програм, коли в них з'явиться вікно.
