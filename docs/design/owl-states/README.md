# Стани сови Gloxi

Автор: **Дмитро Сізьмін**, на геометричній сові Vilna (`docs/design/icons/io.github.stdenis1980.Gloxi.svg`). Ліцензія: [CC-BY-SA-4.0](../../../LICENSES/CC-BY-SA-4.0.txt) (письмова згода автора від 16.11.2026).

Вісім станів, кожен для світлого (`-light`) і темного (`-dark`) тла: `waiting` (чекає), `listening` (слухає), `thinking` (думає), `speaking` (говорить), `done` (готово), `consent` (потрібна згода), `error` (помилка), `offline` (без мережі).

У вікно Gloxi ці стани ще не підключено.
