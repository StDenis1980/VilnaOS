Gloxi 0.1

AI-асистент для GNOME, який говорить із моделлю на вашому комп'ютері й діє лише з вашого дозволу.

Локально за замовчуванням

Мала мовна модель працює на вашому комп'ютері. Без хмари ніщо з написаного вами його не покидає.

Хмара — лише за вашим ключем

Можна підключити будь-який OpenAI-сумісний сервіс власним ключем. Особисті дані маскуються, перш ніж покинути комп'ютер.

Спершу питає

Gloxi працює лише в теках, які ви обрали, і лише через Herkos: він показує, що саме зміниться, питає дозволу й веде журнал.

Чесно про preview

Це рання версія для тестування. У звичайному Linux Herkos працює в тій самій пісочниці, що й Gloxi, тож захист слабший, ніж буде у Vilna OS, де Herkos — окрема системна служба. Не давайте Gloxi доступ до тек, втрата яких вам болітиме, і робіть резервні копії.

Що потрібно

  • Linux з GNOME і Flatpak (openSUSE Aeon, Fedora Workstation, Ubuntu з Flatpak тощо).
  • 64-бітний процесор Intel або AMD; відеокарта не обов'язкова.
  • Від 8 ГБ оперативної пам'яті, краще 16 ГБ; близько 3 ГБ вільного місця для моделі.

Встановлення

Gloxi 0.1 вийде наприкінці січня 2027 року. До того його можна зібрати з коду за інструкцією.

  1. Завантажте gloxi.flatpak і gloxi.flatpak.sha256 з останнього випуску:
    Випуски на GitHub
  2. Перевірте, що файл не пошкоджено і не підмінено: 
    sha256sum -c gloxi.flatpak.sha256
  3. Встановіть середовище GNOME з Flathub (якщо його ще немає) і сам Gloxi: 
    flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub org.gnome.Platform//50
flatpak install --user gloxi.flatpak
  4. Запустіть Gloxi з меню застосунків або командою flatpak run io.github.stdenis1980.Gloxi. Під час першого запуску Gloxi спитає, чи завантажити модель (Qwen3 4B, близько 2,5 ГБ), і перевірить її контрольну суму. Про вас при цьому нічого не надсилається.

Видалити: flatpak uninstall --user io.github.stdenis1980.Gloxi (додайте --delete-data, щоб стерти й модель та налаштування).
