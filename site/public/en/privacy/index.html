Privacy

In short: this site collects nothing about you, and by default Gloxi sends nothing from your computer.

This site

  • No cookies, analytics, counters, ads, embedded videos or social buttons.
  • All fonts, icons and styles are served by this site; your browser does not contact other servers.
  • The site is hosted in Europe. The host briefly sees the technical details of each request (as every web server does) but does not keep your IP address in its logs.

Downloads from GitHub

Gloxi's files and code are on GitHub. When you go there or download a release, the GitHub privacy statement applies. Feedback in GitHub Issues is public.

Gloxi

  • By default Gloxi uses a model on your computer, and your conversations do not leave it.
  • The model is downloaded only after you agree; only the request for the file is sent.
  • You turn the cloud on yourself, with your own key for a service you choose. Personal data is masked on the device before it is sent. What that service does with the masked text is up to its own policy.
  • Gloxi sends us no statistics and no crash reports.

Contact

Privacy questions: GitHub Issues; vulnerabilities: privately, see security.txt.
