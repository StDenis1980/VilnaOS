Vilna OS

A free Linux for all of Europe, with an assistant that hears everything but acts only with your permission. Free as in freedom.

The Gloxi assistant

Runs a small model on your own computer. The cloud is used only if you turn it on, and personal data is masked on the device first.

Nothing without permission

Every action goes through a security layer: risky ones are shown to you first, everything is logged, and changes to files can be undone.

Open source

The system, the assistant and the security layer are GPL-3.0-or-later. Built on openSUSE Aeon: an immutable system with transactional updates.

What you can try now

The first step is Gloxi 0.1 preview: the assistant as an app for any Linux with GNOME. The Vilna OS image comes later.
