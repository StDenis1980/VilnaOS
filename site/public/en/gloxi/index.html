Gloxi 0.1

An AI assistant for GNOME that talks to a model on your own computer and acts only with your permission.

Local by default

A small language model runs on your computer. Without the cloud, nothing you write leaves it.

Cloud only with your key

You can connect any OpenAI-compatible service with your own key. Personal data is masked before it leaves your computer.

Asks first

Gloxi works only in the folders you choose, and only through Herkos, which shows what will change, asks you and keeps a log.

An honest word about the preview

This is an early version for testing. On a regular Linux, Herkos runs in the same sandbox as Gloxi, so the protection is weaker than it will be in Vilna OS, where Herkos is a separate system service. Do not give Gloxi folders you cannot afford to lose, and keep backups.

What you need

  • Linux with GNOME and Flatpak (openSUSE Aeon, Fedora Workstation, Ubuntu with Flatpak and so on).
  • A 64-bit Intel or AMD processor; a graphics card is optional.
  • At least 8 GB of RAM, 16 GB is better; about 3 GB of free space for the model.

Install

Gloxi 0.1 comes out at the end of January 2027. Until then you can build it from source.

  1. Download gloxi.flatpak and gloxi.flatpak.sha256 from the latest release:
    Releases on GitHub
  2. Check that the file is complete and has not been replaced: 
    sha256sum -c gloxi.flatpak.sha256
  3. Install the GNOME runtime from Flathub (if you do not have it yet) and Gloxi itself: 
    flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub org.gnome.Platform//50
flatpak install --user gloxi.flatpak
  4. Start Gloxi from the app menu or with flatpak run io.github.stdenis1980.Gloxi. On the first start Gloxi asks before it downloads the model (Qwen3 4B, about 2.5 GB) and checks its checksum. Nothing about you is sent.

To remove it: flatpak uninstall --user io.github.stdenis1980.Gloxi (add --delete-data to erase the model and settings too).
