# Ліцензування

У Vilna дві ліцензії, залежно від призначення компонента.

| Ліцензія | До чого застосовується |
| --- | --- |
| **GPL-3.0-or-later** ([текст](LICENSES/GPL-3.0-or-later.txt)) | За замовчуванням увесь репозиторій: ОС і образ (`image/`), асистент Gloxi (`gloxi/`), шар безпеки Herkos (`herkos/`), документація |
| **Apache-2.0** ([текст](LICENSES/Apache-2.0.txt)) | Спільні компоненти, які мають вільно використовуватися поза Vilna: шлюз приватності (`privacy-gateway/`), MCP-сервери інструментів (`mcp/`), SDK (`sdk/`). Такий компонент має власний файл `LICENSE` у своїй папці, і саме він діє для цієї папки |

Чому так:

- **GPL-3.0-or-later** для ядра продукту: хто змінює й поширює Vilna, Gloxi чи Herkos, мусить відкрити свої зміни. Відкритий Herkos — це ще й умова довіри до шару безпеки.
- **Apache-2.0** для спільних компонентів: їх можна вбудовувати в будь-які проєкти, зокрема в GPL-проєкти, а явний патентний дозвіл спрощує використання компаніями.

Комерційні продукти (хмара Guamoko, агенти, платні функції) розробляються окремо і з'єднуються з Vilna лише через відкриті інтерфейси (OpenAI-сумісний API, MCP, D-Bus), тому на них ліцензія цього репозиторію не поширюється.

## Позначення у файлах

Кожен файл з кодом починається з SPDX-позначки, наприклад:

```
SPDX-License-Identifier: GPL-3.0-or-later
```

або `SPDX-License-Identifier: Apache-2.0` для спільних компонентів.

## Внески

Перед прийомом зовнішніх внесків буде запроваджено угоду автора внеску (CLA), щоб зберегти можливість змінювати ліцензію окремих компонентів. Текст CLA ще готується.
