# Шлюз приватності

Бібліотека, яка на пристрої знаходить і маскує чутливі дані (імена, контакти, номери документів тощо), перш ніж запит піде у хмарну модель, і повертає справжні значення у відповідь. У Gloxi вона стоїть між маршрутизатором моделей і хмарою та увімкнена за замовчуванням.

> Стан: коду ще немає. Код буде перенесено з власних напрацювань засновника (за [roadmap](../docs/roadmap.md) — 30 листопада — 20 грудня 2026). Тестові дані — лише синтетичні.
